Detailed Description

Tree queries.

Author
karurochari
Date

The query API is an explicit, handle-free builder: steps are appended with plain method calls and evaluated iteratively, with a predictable and bounded memory footprint.

Steps, in order:

  • accept() : emit the current node and stop the branch.
  • child() : move to the children of the current element.
  • descend() : move to every descendant of the current element.
  • fork() : stay on the current node and every descendant.
  • match_type/match_ns/match_name/match_value/match_text/match_attr: filter the current node; the branch is pruned on no match.

A branch that reaches the end of the steps is emitted implicitly.
